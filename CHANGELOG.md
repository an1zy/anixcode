# Изменения

## 0.9.0

- Поддержка серверов Model Context Protocol (MCP): локальные (stdio) и удалённые (Streamable HTTP)
- Команда `/mcp` для управления серверами: `add`, `remove`, `on`, `off`, `tools`, `reload`
- Настройка `mcp_servers` в `settings.json` (совместима с форматом Claude Desktop и Cursor)
- Точечные разрешения для MCP-инструментов в режиме запроса подтверждений
- Поддержка MCP в консольном режиме `anixcode run`
- Статус MCP-серверов в `/status` и `/doctor`

## 0.8.0

- Английский интерфейс: язык по системе, переключение `/language`; README на английском (и README.ru.md)
- Чёрно-белая тема теперь называется Noir; OpenRouter убран из списка провайдеров
- Исправлено на Windows: свои команды в кодировке cp1251, клонирование по локальному пути
- Поиск больше не подвешивает интерфейс; лимит по времени и пропуск AppData

## 0.7.1 — первая публичная версия (alpha)

- Агент с инструментами: read, ls, glob, grep, edit, write, bash (PowerShell на Windows)
- Любой OpenAI-совместимый провайдер + свои провайдеры, выбор модели из списка
- Интерфейс на Textual: стриминг, карточки действий, diff, темы ANIX и OpenCode, анимации
- Режимы Build / Plan, разрешения строкой над вводом, полный доступ (F2), красная подсветка опасных команд
- `/undo` и `/redo`, автосжатие контекста, повторы при сбоях сети и лимитах
- `@файлы` с подсказками, `/init`, `/review`, `/commit`, `/test`, `/fix`, `/explain`, `/pr`, свои команды из `.md`
- `!команда`, `# заметка` в AGENTS.md, сессии, выбор проекта с дисками и клонированием
- Статус в Discord через AI-RPC
